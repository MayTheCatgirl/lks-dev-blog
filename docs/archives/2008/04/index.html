真芽さん からのお便り

はじめまして、ゲーム大好きおばさんです。

昨年の任天堂カンファレスのプロモーションビデオで、
ドンキホーテを彷彿させてくれるハウザーを見て以来。
発売が今か今かと楽しみに待っているんですよ。
ワラワラＲＰＧとは、面白い命名ですね。
なんだかそれだけでも、購買意欲をそそられます。

難しいアクションやシュミレーションとは違い、ほのぼのとマイペースで
年齢も関係なく遊べそうなのがうれしいですね。
開発大変でしょうが、頑張って下さい。

～きむＰより～

こんばんにゃん。真芽さん。きむＰです。にゃん
応援あんがと～。
正直、今、とてもピンチです。
あまりピンチの内容は細かく話せませんが
ピンチ×３くらい。

そんなとき、こんな風にストレートに応援してくれた
真芽さんのお言葉、胸が熱くなる。

開発一同、がんばります。

swoopさん からのお便り

姫さんが何人か出てくるみたいですが、
もしかして牧場物語のように“選ぶ”んですか……！？


～きむＰより～

こんばんにゃ。swoopさん。きむＰです。
姫が何人か・・・。
１，２，３，４，５，６・・・、７人の不思議な王様たちが
いたいけな姫様たちを隠し持っているので・・、ずばり、７人です。

ラッチーセブン。

牧場物語に結婚があるように
このゲームにも形は違えど・・・愛があります（笑）
あれもラブこれもラブ（懐！！）


７人の姫様の紹介は順番に
ちょこっとずつやっていくので、

みなさん、お楽しみに～。

あ～さん からのお便り

ゲーム内の発音は英語で決定なんでしょうか？
あの変な発音がかわいくて好きだったのに・・・。


～きむＰより～

あ～さん、こんちわチワワ。
きむＰです。

そうっすよね～。英語より、あれのほうがよいですよね～。

ゲーム内の音声は、ずばり「英語」ではありません。
そして「フランス語」でもありません。

ヘンテコ語です。
でも、これがまた、大変でねぇ。
さらにレベルアップしたヘンテコ語をめざすために、日々、
効果音担当の安達さん（Ｍｏｏｎの音担当と同じ人）が
無茶苦茶、がんばってくれています。

ヘンテコ語がすばらしくヘンテコに
完成するのが待ち遠しいですな～。
