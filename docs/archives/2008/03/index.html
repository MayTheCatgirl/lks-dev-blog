そらさん　からのお便り

はじめましてこんばんは。

開発ブログが立ち上がってからずっと、
毎週金曜日を楽しみに拝見しております。

自分の好きな製作スタッフさんたちがこれほど集まった作品、
というのは今までになかったので、ものすごく期待しているんです。
今一番気になっていることは、やはり発売時期についてなのですが…
良い作品のためなら、いくらでも待ちますのでどうぞめいっぱい
「楽しいこと」を詰め込んでくださいね！

素敵なゲームの完成を、いちユーザーとしてファンとして、
すごくすごく楽しみにしています。


～きむＰより～
発売時期・・ですね。春・・にしたいんですが、ぎりぎりまで粘らせてください。
面白いゲームにしてからださないと、納得できないよね。やっぱ。

なんのために出すかというと、商品を売るためってのはあるけど、
そんだけじゃない。
面白い作品を商品にして、みんなで楽しむため。につくってるはず。

商売なんで、色々なことでこだわりつづけられないことも、
ぶっちゃけあります。でも、やっぱりそれでも「面白い」をめざしたい。
真のギリギリ、リミットまで。

Seinさん　からのお便り

相変わらず・・・というか、益々大変そうですね。
体には気をつけて、でも、良いものを完成させてください。
わくわく、楽しみにしながら待っています。
トコロで、ちょっとお願いなのですが、王様物語の壁紙って
作る予定はないでしょうか？
今の段階では難しいのかなーっとは思うのですが、
可愛いキャラクターたちや、設定の絵、ゲームの画面の雰囲気等々、
とっても大好きなので、ちょっと落ち着いて、ちょっと余裕ができたら・・・
で良いので、作って欲しいなあと思います。
負担にならない程度に、ご検討くださいませ。


～きむＰより～
いやー、毎度毎度、応援のお手紙ありがとうございます。
か、壁紙か・・・。うーん。またもや。
うんうん、かわいい壁紙ほしいよね。僕も大賛成。

えーと、まだ、本番の公式サイトで発表する壁紙はつくってるところなので
公開できないんです・・・。:-(。

うーむ。なんか、ちょっと根負けした。
えーい、１枚だしちゃうか！

今回は・・僕が個人的につかっている
壁紙をアップしちゃいます（笑）

黒ベースで、仕事のファイルがみやすいようになっているので
ちょっと地味・・なんですが、もしよければ、みなさんも、どうぞ～。

ぴ、ＰＲ大臣の中村さんと高島さんに「こらこら」とつっこみいれられそうですが、
のっけちゃいましょう（笑）
本当、プライベートなものなんで、なんかはずかしいですが。
今回はこれでゆるして！＞ぽんたさん　Seinさん
