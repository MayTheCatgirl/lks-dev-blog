ラロクさん からのおたより

スタッフの皆さんこんにちは！
少しずつ露出してきた王物の情報を
発売を楽しみにしつつ見ています。

発売予定が今春から夏予定になっていたのですね。
そろそろ発売予定日が出てくるかな？と
思っていたのでちょっと寂しい気分です。

でもその分スタッフの方々のやりたい事や表現したい事が
いっぱい詰まったものが出来ると信じて楽しみに待たせていただきますね！

蛇足ですが……
自分の誕生日が元々海の日なので
二十歳の自分への誕生日プレゼントとして買えたらいいな～
なんて思っています♪

なにはともあれ期待していますっ
追い込みの大変な時期だとは思いますが、スタッフの皆さん頑張ってくださいな

～牛騎士ハウザーより～

ラロク殿

我輩はハウザー。ハウザー・オレガノシュタイン！

なんとすばらしいおかたじゃ。
我が愛牛のパンチョも、モウモウと喜んでおりますぞ。
しかしながら、開発スタッフは今非常にピンチであるとも
聞いておる。きむＰ＋開発スタッフの健闘を祈～る！
