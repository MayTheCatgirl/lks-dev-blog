「マベドリ」ってなんだ！？

こんにちは、ＰＲ大臣です。

「Nintendo DREAM」（通称ニンドリ）６月号にて、
一冊ぜ～んぶマーベラスのゲーム情報が載りまくりの
「Marvelous Entertainment DREAM」という雑誌が発表されたのはご存知でしょうかっ！？

略して「マベドリ」！（画像はイメージです）
発売日は６月４日（木）頃。
すっかりお待たせしている『王様物語』の情報も掲載されるとのこと！
和田＆木村の（秘）コメントが見どころとなっています。


また、マベドリ編集部さんによるブログ
「マベドリだより」もチェックしてみてくださいね。

「マベドリ」では、読者の皆さんのイラストやお便り、質問などなど、大募集中です！
「募集期間が短いよ～」という声にお応えして、〆切が「5/13（水）必着」に延長されたようですのでどしどし応募してください。
応募方法の詳細は「マベドリだより」をチェキ！
